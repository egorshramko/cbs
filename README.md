## Cinema Booking System

В каталоге scripts лежит файл generate-sessions.example.py как пример для генерации сеансов на бекенде на ближайшие 2 дня. 
В нем нужно поменять данные для подключения к БД на собственные локальные.

Для запуска generate-session.example.py, нужна библиотека psycopg2. Чтобы ее установить, выполните
```
pip install psycopg2-binary
```
